# 印记 · 离线照片水印

一个无需安装、完全在浏览器本地运行的照片文字水印工具。无账号、无后端、无第三方依赖。

## 在线使用

打开 [印记 · 照片水印](https://0xaptx.github.io/photo-watermark/) 即可使用，无需安装。加载网页需要联网，照片的读取、处理与导出均在本机浏览器完成，不会上传照片。

## 离线使用

1. 下载本仓库：在 GitHub 页面点击 **Code → Download ZIP**，解压。
2. 用现代浏览器打开 `dist/index.html`，无需启动服务器，也无需联网。
3. 选择或拖入照片，设置水印文字、位置、字号、颜色、透明度和旋转角度。
4. 保存当前照片，或批量保存全部照片。

批量导出时，浏览器可能要求允许下载多个文件。原照片不会被修改。

## 功能

- 支持 JPEG、PNG、WebP 输入，可一次选择多张照片。
- 支持四角、居中和全图平铺水印。
- 自定义文字、相对字号、颜色、透明度、角度和阴影。
- 实时预览，按原始像素尺寸导出 PNG 或高质量 JPEG。
- 全部照片共用一组水印设置，支持逐张查看和批量下载。

## 隐私与安全

- 照片通过浏览器 File API 读取，在本机 Canvas 中处理。
- 无照片上传、统计追踪、远程字体、外部脚本或网络接口。
- 页面设置了 Content Security Policy，其中 `connect-src 'none'` 禁止页面主动建立网络连接。
- 重新编码输出，不复制原照片的 EXIF 等元数据；不保证保留原图色彩配置。
- 发布在这里的只有程序源码，不含用户照片。

需要完全断网使用时，请下载后离线打开。在线版本仅由 GitHub Pages 提供静态页面。

## 开发

核心实现为 `dist/index.html`，包含页面样式与原生 JavaScript。无需构建或安装依赖。

使用浏览器打开该文件即可调试。主要使用 File API、Canvas 2D、Blob 和对象 URL。

推送到 `main` 分支时，GitHub Actions 会自动将 `dist/` 发布到 GitHub Pages。

## 已知限制

- 暂不支持图片 Logo 水印、HEIC、RAW、动图或视频。
- 超大图片和一次载入大量照片可能受到浏览器内存限制。
- 批量导出会分别下载多个文件，暂不打包 ZIP。
- 文字超出画布或旋转后靠近边缘时可能被裁切，请先检查预览。
- 水印不能保证防止图片被复制或水印被去除。
